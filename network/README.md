# Network examples

This directory contains public, placeholder-only examples for host-level network
configuration. Live tunnel IDs, credential paths, ingress domains, addresses, and
host inventory are operator-local data and must not be committed.

The local [`check-tailscale-auth.py`](check-tailscale-auth.py) check validates a
running, online Tailscale identity and an explicit `disabled` or `monitored`
node-key expiry policy without printing the host's DNS name or addresses. The
NAS health snapshot runs it every 15 minutes. Use the public, placeholder-only
[`Tailscale authentication recovery runbook`](../runbooks/tailscale-auth-recovery.md)
for an attended `NeedsLogin` recovery and post-reboot verification.

The local [`check-link-health.py`](check-link-health.py) check watches each
configured wired interface for a speed below its expected minimum, kernel link
drops, PHY downshifts, and NIC error growth, so a flapping or negotiated-down
link is reported even when a fallback route keeps services up. Start from
[`link-health.example.conf`](link-health.example.conf); see
[`../docs/link-health.md`](../docs/link-health.md).

[`brokkr-eee-off@.service.example`](brokkr-eee-off@.service.example) is a
systemd template that keeps Energy Efficient Ethernet off on one wired
interface; the instance name is the interface. Deploy it with
`scripts/deploy-eee-off.sh`, which adopts an existing ad-hoc EEE-off unit. See
[`../docs/eee-off.md`](../docs/eee-off.md) for why EEE stays off and why it was
not the cause of the 2026 link flapping.

## cloudflared

Copy [`cloudflared/config.example.yml`](cloudflared/config.example.yml) to the
ignored `cloudflared/config.yml`, then replace the placeholder UUID, hostname, and
service URL. The credentials JSON is a secret generated by Cloudflare and belongs
only on the target host.

```bash
cp network/cloudflared/config.example.yml network/cloudflared/config.yml
$EDITOR network/cloudflared/config.yml
cloudflared tunnel ingress validate
```

Applying a tunnel change is intentionally manual because it changes externally
reachable infrastructure. One generic sequence is:

```bash
scp network/cloudflared/config.yml brokkr@control-node:/tmp/cloudflared.yml
ssh brokkr@control-node \
  'sudo install -m 600 /tmp/cloudflared.yml /etc/cloudflared/config.yml && \
   sudo systemctl restart cloudflared'
ssh brokkr@control-node 'systemctl status cloudflared --no-pager'
```

Validate that the local config contains no live values before committing. The live
`config.yml` is ignored, so only updates to `config.example.yml` should appear in Git.
